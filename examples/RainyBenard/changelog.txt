2026-11-10  v033 stencil CNN for the simulations_v2 data (round 1; not yet trained)
-----------------------------------------------------------------------------------
- Decisions (with the user): the calibration stage continues with the v032 architecture (3x3
  receptive field, 32 -> 64 -> 64, ReLU, periodic and ghost-value padding, Adam 1e-3,
  ReduceLROnPlateau, early stopping, seeds 42-44, per-run relative-MSE loss, no reweighting of
  plume cells). Each target gets the inputs its term depends on:
    Q_d_a   b, log10 Ra -> Q_d          Q_d_b   b -> Q_d / kappa (= Lap b)
    Q_c_C1  b, q, z     -> Q_c          Q_c_C2  b, q - q_s, z -> Q_c
    Q_c_C3  b, q        -> Q_c          Q_c_C4  b, q - q_s    -> Q_c
  (a 2 x 2 design {q, q - q_s} x {with z, without z}; Q as a whole later). log10 Pr dropped (Pr = 1).
  Split by time block within every training run: training frames 25..750, validation frames
  811..1000 (a 60-frame gap, 3 x the longest decorrelation time of the unsteady runs; Roberts et
  al. 2017), every 3rd frame. Frames 0..24 (no convection, kinetic energy < 1e-4) unused. Test runs
  Ra 8.7e6 and 1.5e8 (never loaded in training); Ra 2e8 dropped from the test set (under-resolved
  top boundary layer). Block placement from the kinetic-energy time series (tmp/v2_checks/ts_*.npz):
  the final 20% block holds on average 22% of each run's top-10% kinetic-energy frames (0-40% per
  run, 0 for Ra 7.5e6), better than 2 or 3 spread blocks, which also lose 3-5x more frames to gaps.
- simulations_v2/v033 stencil CNN.py (new; port of simulations/v032 stencil CNN.py): v2 run lists;
  Ra, Pr and grid from bou.in and alpha, beta from humid.in through postprocess.py; 128 x 2048;
  CONFIGS; each array reduced to the frames used right after it is read; normalisation from the
  training frames only; run weights per run and block. Usage: python "v033 stencil CNN.py" <config> [seeds].
- simulations_v2/tests/test_v033_stencil_cnn.py (new; port of the v032 test): padding and Laplacian
  on the 128 x 2048 grid, receptive field, and frames, inputs, targets, normalisation, weights,
  generator and refusals on synthetic run folders; end-to-end smoke test. All pass
  (tmp/v033_tests/test_v033.log). Independent review: no leakage or bookkeeping errors; no changes.
- .gitignore: the v033 script un-ignored.

2026-11-10  convergence test of the finite-difference Db/Dt against Q_d + Q_c
-----------------------------------------------------------------------------
- Read-only check (tmp/fd_vs_rhs/check_fd_vs_rhs.py, tmp/fd_vs_rhs/check_fd_vs_rhs.log; 19 frames
  per run, all 11 runs): the stored key Q (central difference of the 1-time-unit frames plus
  flux-form advection) against Q_d + Q_c. The post-processing stencils are the solver's own
  (ExplicitTermsTemp.F90; ImplicitAndUpdateTemp.F90 with second_derivative_coeff in grid.F90;
  AddCondensation in moisture.F90; kappa = 1/pect = (Ra Pr)^-1/2), so the difference is time
  discretisation only. Median relative RMS difference: 2.8e-8 at Ra 1e6 (steady; best frame
  6.6e-11), 2.0e-4 at 5e6, 5.8e-3 at 7.5e6, 4-10% at 8.7e6-2.5e7, 16% at 5e7, 29% at 1e8,
  45-58% at 1.5e8 and 2e8; >= 1 in burst frames at Ra >= 1e7. Doubling the frame spacing
  multiplies it by 2.9-3.5 and a 4th-order stencil reduces it 2-6x, so the truncation error of
  the frame differencing dominates.
- To measure the convergence directly: simulations_v2/Convergence test/ (new).
  make_convergence_runs.py creates Ra_1e6_Pr_1 (steady: a control) and Ra_1e8_Pr_1 (a convective
  event is under way at t ~ 995-1000): restarts from the end state (t = T0 = 1000.0099999992) of
  the training runs of the same name, for 10 time units, with a movie frame at every step.
  bou.in differs from the source run's only in NREAD 1 IRESET 1, TMAX 10.0 and TFRAME 1e-2.
  IRESET 1 is required: movie frame keys are nint(time/TFRAME) in 5 digits
  (src/h5tools/h5_tools.F90), which would overflow at t ~ 1000 with TFRAME 1e-2. Frame k is at
  T0 + 0.01 k. humid.in and outputdir/continua_*.h5 copied unchanged (md5 in each setup.txt);
  the source runs are only read. run_convergence.sh runs both at once (4 MPI processes each;
  provenance.txt, run.log ending in EXIT, convergence.log); launched by the user in WSL.
  Expected about 10.5 GB of movie per run. .gitignore: the folder's *.py and *.sh un-ignored.
  Setup reviewed by an independent agent: no blocking issues.
