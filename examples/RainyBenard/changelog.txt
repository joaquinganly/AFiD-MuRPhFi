Rainy-Benard + ML project: changelog
=====================================
Newest entries first. Each entry: what changed, why, and where (files, logs).
Paths are relative to examples/RainyBenard/ unless they start with src/, tools/ or tmp/
(those are relative to the repository root). Logs in tmp/ are on the Lenovo Legion only.


2026-11-09  simulations_v2 post-processing (Q_d, Q_c, Q) and GIFs
-----------------------------------------------------------------
- simulations_v2/postprocess.py: post-processing of the v2 runs, ported from the established
  pipeline (simulations/Staggered grid corrected/flat_layout_copies/: "Q staggered grid
  efficient pathing.py", "saves_q_npz.py", "Qc and Qd only.py") with the same formulas, file
  names, keys and (nz, ny, nt) float64 layout, so the v032 loaders can read the output.
  Changes from the old scripts: input is outputdir/flowmov/movie_zcut.h5 (the v2 runs write no
  fields/ files); Ra, Pr, grid and TFRAME are read from bou.in, alpha, beta, gamma and tau from
  humid.in (they were parsed from folder names or hard-coded); buoyancy wall values 0 and
  beta - 1 (src/flow_solver/SetTempBCs.F90, moist case); existing outputs are never
  overwritten; <run>_fields_Q.npz and <run>_q.npz are written uncompressed (the old
  compressed field files were 89-96% of their raw size; Q_c compresses to 8%).
  Per run: <run>_fields_Q.npz (u, v, theta, rel_q, Q), <run>_q.npz (q), Q_d_c.npz (Q_d, Q_c),
  postprocess.txt (provenance). The key Q in <run>_fields_Q.npz is the old pipeline's
  finite-difference estimate of Db/Dt from the frames; the training target Q is Q_d + Q_c.
  v is the horizontal velocity as stored by AFiD, half a cell offset in y (unchanged).
- Tests: simulations_v2/tests/test_postprocess.py, run as a script (pytest is not in the
  Docker image). It checks that the outputs match the old pipeline's stored outputs for the
  old run Ra_5e6 (to 1e-12), that movie_zcut.h5 is identical to fields/*.h5, that the
  parameters are parsed correctly, and runs end to end on a synthetic run folder. All pass.
- Run on all 8 runs (about 13.6 GB per run, 109 GB in total): tmp/postprocess_v2.log.
  Data check (tmp/v2_gifs/check_postprocess_v2.py, tmp/v2_gifs/check_postprocess_v2.log):
  every run has 1001 frames, all values finite, Q_c >= 0. The domain budget d<b>/dt =
  <Q_d + Q_c> holds with correlation 1.000 and relative RMS difference 0.3-2.6% (frame
  differencing). Pointwise, the finite-difference Q agrees with Q_d + Q_c to < 0.1% relative
  RMS at Ra <= 5e6 and 0.6% at 7.5e6, but only to 5-33% at Ra >= 1e7 (consistent with the
  frame spacing of 1 time unit not resolving db/dt during bursts; not tested further).
  Q_c > 0 at 1.4-5.3% of points (in the plumes, see the GIFs).
- GIFs: simulations_v2/figures/v2_{b,Q_d,Q_c,Q}.gif (all 8 runs, every 5th frame, plus a
  t = 500 PNG per field); script tmp/v2_gifs/make_gifs.py.
2026-11-09  simulations_v2 batch finished and checked
----------------------------------------------------
- All 8 runs ended normally (TMAX reached, run.log ends in "EXIT 0"; queue finished
  2026-11-09 02:45; 3.2-3.4 h per run, two at a time). 1001 frames each (t = 0..1000),
  about 10 GB per run.
- Numerical checks, every frame: max CFL 0.25-0.53; b >= 5.86e-3 and q >= 2.8e-4;
  no windows of three alternating extrema in a row along y or z in any run except
  Ra 1e8 (6 along z in the worst frame); grid spacing / (pi x Kolmogorov length)
  0.11-0.60 (Groetzbach 1983: <= 1); 6.9-21.6 cells in the thinnest boundary layer
  (Shishkina et al. 2010 minimum: 2.8-5.5).
  Script and outputs: tmp/check_v2_runs.py, tmp/check_v2_runs.log, tmp/v2_checks/.
- Flow states (w at mid-height over the whole run: tmp/v2_checks/w_hovmoller.png):
  Ra 1e6 one steady plume; 5e6 one plume, kinetic energy oscillating with period ~117;
  7.5e6 one long-lived plume plus short bursts elsewhere (period ~140); Ra >= 1e7
  isolated short-lived plumes separated by quiet intervals (e.g. t ~ 50-330 and
  430-650 at Ra 1e8), each burst followed by disturbances spreading sideways across
  the box. |w| > 0.01 at mid-height in only 1.3-2.9% of (y, t >= 50).
- Not statistically steady at Ra >= 1e7 by t = 1000 (tmp/m_budget.py, tmp/m_budget.log,
  tmp/v2_checks/m_budget.png): the domain mean of m = b + 2q is still falling
  (3.3-7.8e-5 per time unit; same sign and size as kappa (Nu_bot - Nu_top), which
  differs by 3-42%) and the time-mean m flux over t in [500, 1000] varies with height
  (Nu_m 1.39 -> 1.52 at 1e7, 1.26 -> 1.79 at 5e7). Ra 1e6 settles by t ~ 250
  (Nu_m = 1.49 at every height); 5e6 and 7.5e6 nearly settle by t ~ 750.

2026-11-08  simulations_v2 dataset (Lenovo Legion, WSL2)
-------------------------------------------------------
- CLAUDE.md, section 6: every change to code, simulation setup, datasets or experiment
  configuration is now logged in this changelog and committed together with the change.
- Launched the v2 batch (queue started 13:40):
    8 runs, Ra = 1e6, 5e6, 7.5e6, 1e7, 1.75e7, 2.5e7, 5e7, 1e8 (Ra list of Vinograd &
    Clark Di Leoni 2025, J. Fluid Mech. 1006, A10), Pr = 1.
    Grid 128 x 2048 (NXM vertical x NYM horizontal), box 1 x 16, uniform;
    dt = DTMAX = 1e-2 fixed (IDTV 0),
    CFLMAX 1; TMAX 1000, WALLTIMEMAX 1e8; TOUT = TFRAME = 1, SAVE_3D 6000.
    Start: drizzle state + 1e-3 noise (NREAD 0, drizzle.h5 written by tools/drizzle.py).
    humid.in unchanged (alpha 3, beta 2, gamma 2, tau 0.1, dry top, saturated bottom).
    Queue: 2 runs at a time, 4 MPI processes each (mpiexec --bind-to none afid 4 1),
    highest Ra first; per run provenance.txt and run.log ending in "EXIT <code>".
    Files: simulations_v2/make_runs.py, simulations_v2/run_queue.sh,
    simulations_v2/runs/Ra_<Ra>_Pr_1/{bou.in, humid.in, drizzle.h5, setup.txt},
    simulations_v2/queue.log. Setup check: tmp/make_runs.log; queue dry run: tmp/test_queue.log.
- Run folders are generated by script from one (Ra, Pr) list, so folder name and bou.in
  cannot disagree (a hand-made pilot folder named Pr_1 had PRAT 0.5). Ra and Pr are read
  from bou.in, and folder names carry the decimal point (Ra_7.5e6_Pr_1).
- Pr fixed at 1 for all runs rather than varied with Ra: varying Pr together with Ra would
  confound the two effects, and Pr = 1 matches Vinograd & Clark Di Leoni (2025) and the
  group's reference setup. Viscosity still varies 10x through Ra (nu = kappa = Ra^-1/2).
- P1 pilots at the extremes (simulations_v2/pilots/P1_128x2048_dt1e-2/, Ra 1e6 and 1e8,
  Pr 1, t = 50): max CFL 0.23 / 0.48; b >= 0.006 and q >= 7e-4 in every frame; no 2-cell
  oscillations; grid spacing / (pi x Kolmogorov length) = 0.11 / 0.61; >= 6.5 cells in the
  thinnest boundary layer. Logs: tmp/check_p1_runs.log, tmp/p1_wiggles.log.
- Initial condition changed from the solver's cold-start humidity blob (q ~ 9x saturation)
  to the drizzle state + noise (as in the group's reference setup): the blob gave b < 0 and
  q < 0 at Ra >= 1e7 on both grids tried (64 x 1024 and 512 x 1024), with steep horizontal
  fronts 1-2 cells wide.
  Logs: tmp/b_check_pilot.log, tmp/b_where_pilot.log, tmp/check_pilots_v2.log,
  tmp/pilot_fronts.log.
- dt set to 1e-2 (= 0.1 tau, as in the group's reference setup). At this dt the vertical
  grid is limited by CFL <= 1 (NXM = 512 would exceed it): tmp/drizzle_cfl.log. The explicit
  horizontal-diffusion limit that made Pr_05_Ra_1e4 unstable at dt 1e-2 (2026-11-06 entry)
  is not reached for Ra >= 1e6 at Pr 1: linear estimate <= 1.4 against the RK3 limit 2.51
  at 128 x 2048.
- Box kept at 1 x 16: smaller boxes constrain the late-time aggregated state.
- Found: old-dataset folders Ra_75e6, Ra_25e7, Ra_175e7 were run at Ra = 7.5e6, 2.5e7 and
  1.75e7 (kappa inferred from each run's chiT; tmp/kappa_from_chiT.log), not at 7.5e7,
  2.5e8 and 1.75e9 as parsed by extract_ra_pr() in the v031/v032 scripts and as stated in
  CLAUDE.md. Their stored Q_d (Q_d_c.npz) was computed with the parsed kappa.
- MPI tests (simulations_v2/mpi_tests/): 512 x 1024, 500 steps: 3.4 / 6.6 / 8.2 steps/s with
  2 / 4 / 8 processes; 16 processes refused by Open MPI (not enough slots).
- Old-run time scales for choosing TMAX (spin-up ~100-150, b decorrelation 3-20 time
  units, bursty kinetic energy at Ra 5e6-5e7): tmp/run_timescales.log,
  tmp/ke_timeseries_old_runs.png.
